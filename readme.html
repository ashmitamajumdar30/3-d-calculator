# 🧮 3D Simple Calculator A beginner-friendly, fully functional web-based calculator featuring tactile 3D CSS styling. Built with pure HTML, CSS, and Vanilla JavaScript. ## 🌟 Features * **3D UI Design:** Uses CSS `transform: perspective()` and clever `box-shadow` techniques to create a tilted, physical-looking device. * **Tactile Buttons:** Buttons physically compress down when clicked using the CSS `:active` state. * **Human-Readable Code:** Designed with simplicity in mind. The JavaScript uses straightforward functions making it easy for beginners to read and modify. * **Error Handling:** Protects against invalid inputs (e.g., double math operators) and briefly displays an "Error" state before resetting. ## 🚀 How to Run 1. Clone or download this repository. 2. Open `index.html` in any web browser. 3. Click the numbers and operators to perform basic math! ## 🛠️ Built With * **HTML5:** Layout and grid structure. * **CSS3:** 3D rendering, shading, and click animations. * **Vanilla JavaScript:** Math logic and DOM manipulation. ## 🔮 Future Improvements Want to make this project your own?
